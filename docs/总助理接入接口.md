# 开店 Agent 接入个人总助理接口

## 1. 角色边界

个人总助理 Agent 是主控：

- 管理用户目标、日程、文件、提醒、跨项目任务
- 调度不同垂直 Agent 或 Skill
- 保存最终文档和项目成果

开店 Agent 是垂直专家：

- 负责开店画像、选址、财务、办证、营销、风险诊断
- 处理开店相关图片、视频、地图、竞品、知识库
- 输出结构化结论，不直接越权操作用户电脑

## 4. 多模态现场诊断任务

输入：

- 门头照片
- 左右邻铺照片
- 对面街景照片
- 360 度环拍视频
- 地图截图或平台截图

处理流程：

1. 抽取图片/视频关键帧
2. 识别门头、遮挡、台阶、围栏、停车、竞品、聚客点
3. OCR 识别招牌、价格、地图文字、平台截图文字
4. 输出观察事实、风险点、补拍建议
5. 结合选址知识和用户经营品类给出初步判断

输出重点：

- 这个铺位“看起来哪里有问题”
- 还缺哪些角度或数据
- 哪些问题必须实地蹲点验证
- 是否值得继续谈租金/转让费

## 5. 总助理协同示例

用户对总助理说：

> 帮我看看这几张铺位照片，适不适合开早餐店。

总助理应该：

1. 建立或选择一个开店项目档案
2. 把图片和上下文交给开店 Agent
3. 拿到结构化诊断结果
4. 保存报告到项目文件夹
5. 给用户安排下一步，比如“周六 7:00-9:00 去蹲点”

开店 Agent 不应该直接负责日程提醒和文件归档，它只返回结构化行动建议，由总助理执行。
