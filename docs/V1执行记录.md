## 关键命令

审计知识源：

```bash
python3 开店Agent.py --audit
```

构建 RAG 索引：

```bash
python3 scripts/build_rag_index.py
```

OCR 指定页码：

```bash
python3 scripts/ingest_documents.py --ocr --start-page 238 --end-page 245 --append
```

审计视频转写状态：

```bash
python3 scripts/video_processor.py --audit
```

转写指定视频：

```bash
python3 scripts/video_processor.py --use-whisper --whisper-model small --title-contains "第三节1选址流程" --limit 1
```

重建视频 master：

```bash
python3 scripts/video_processor.py --rebuild-master
```
