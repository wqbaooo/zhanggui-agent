## 一、产品定位

掌柜Agent 当前只服务一个真实对象：

```text
新余恒太城五楼大口章鱼烧
```

它是一个以利润增长为目标的 **AI 单店经营 Agent**，不是加盟顾问、不是通用餐饮 SaaS、不是外卖平台、不是 POS 替代品。

核心流程：
```text
说话 / 拍照 / 截图 / 上传资料
  -> Agent 识别来源和字段
  -> 用户确认
  -> 写入这家店的经营档案
  -> 自动分析利润、库存、人工、渠道、SOP 和风险
  -> 生成老板能执行的下一步动作
```

最高目标：
```text
在食品安全、商场规则、员工可承受、顾客体验不崩的前提下，持续提高这家店的真实净利润。
```

默认项目 ID：`xinyu-hengtai-dakou`
真实门店数据目录：`project_data/xinyu-hengtai-dakou/`

### 2.2 前端四大区

1. **Agent 工作台** (`/overview`)
   - 今日状态、对话/拍照/截图录入、待确认草稿、主动预警、今日三件事

   - 客如云截图、美团/淘宝闪购/抖音后台截图、进货单、水电单、总部资料、员工档案、合同/规则、周报月报

## 三、本次迭代完成的改动

### 3.1 图片识别结果展示重构

**问题**：之前图片识别后仅生成文本草稿，未实现层级化展示（来源分类、字段提取、Agent联动）。

**修复方案**：新增三栏式识别结果面板

| 栏位 | 内容 |
|------|------|
| 左栏 | 图片缩略图（`aspect-[3/4]` + `object-contain`）、来源标签、文档分类标签、识别置信度 |
| 中栏 | 提取字段卡片（经营数据）或文档事实列表（文档资料），带置信度进度条 |
| 右栏 | 入库去向（`write_targets` 标签组）、Agent 联动（财务/库存/渠道/SOP/食品安全/训练 Agent） |

**关键改动**：
- [overview/page.tsx](file:///Users/wqboo/Code/20-Products/掌柜Agent/web/src/app/(app)/overview/page.tsx#L561-L865) 识别结果面板（约 300 行）
- 图片缩略图从 `object-cover` 改为 `object-contain`，完整显示原图
- 文档型资料展示 `document_facts` 而非"未识别到结构化字段"
- 根据 `write_targets` 动态展示入库去向和对应 Agent
- 新增 `document_class` 标签（如"SOP/效期管理"）
- 新增整体识别置信度进度条

### 3.2 数据流优化

```
上传图片 / Ctrl+V 粘贴
  -> 识别进度浮层（识别→提取→完成）
  -> 层级化结果面板展开
      ├─ 图片预览 + 来源分类标签 + 文档分类标签
      ├─ 提取字段卡片 / 文档事实列表（带置信度）
      └─ 入库去向标签组 + Agent 联动动作
  -> 点"确认写入经营台账"
      ├─ 写入日账
      ├─ 触发财务/库存/渠道 Agent 分析
      └─ 自动刷新今日数据 + 关闭面板
```
