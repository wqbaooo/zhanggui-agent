# 新余恒太城五楼大口章鱼烧｜库存模块设计与审计

## 定位

这不是通用 ERP 或 WMS，而是服务一家小型章鱼烧门店的经营库存闭环。员工只记录当天实际开封或领用的数量；老板负责入库、位置调拨和阶段盘点。

## 真实数据基线（2026-07-27 已重新审查）

- 主来源：老板已填完的 `大口章鱼烧_库存资料补充采集表_含进货记录_2026-07-26.xlsx`；原始商品档案和进货截图均只读保留。
- 活跃档案：52 个可盘库物料 + 22 个设备资产，共 74 项。其中 35 个常用营业物料进入每日使用表，17 个其他物料只在阶段盘点中管理；设备不计入日常耗用、库存金额和补货预测。
- 实盘基线：2026-07-22 已覆盖 49/52 个物料 SKU，当前状态必须显示“校准中”，不得冒充完整库存。
- 进货账：23 张真实订单，按“订单 + SKU”展开；平台、供应商、订单号、规格、数量、单价、运费、优惠、退款、实付和原始截图一一保留。
- 已删除两条会造成误统计的记录：“原店主盘存”不再冒充进货；7 月 5 日总部订单按同一外部订单号去重，仅保留完整凭证记录。
- 平替口径：平替只是同一物料 SKU 的采购来源和规格/成本变化，盘点表只显示商品名、规格和核算单位，不额外标“平替”。

## 门店执行 SOP

1. 营业中：正常开封/领用时不要每次停下登记，纸质表放在固定位置。
2. 打烊后：只在 A4 纵向《每日物料使用登记表》填 35 个常用营业物料的当天实际使用数量，未使用留空；不填员工姓名和签字。工服、清洁耗材、保鲜膜、垃圾袋等非每日物料不放在每日表。
3. 异常：撒漏、变质、过期、破损单独报损，不混在正常使用中。
4. 阶段盘点：老板在需要建立基线、核对差异或采购决策时，分别盘仓库和门店/冰箱；不强制套用每周固定日。

## 库存、成本与毛利闭环

- 账面库存 = 上次实盘 + 实际入库 - 每日使用 - 报损 ± 盘点校准。
- 期间实际耗用 = 期初实盘 + 期间入库 - 期末实盘。每日使用和报损是结构证据，不在实际耗用公式中二次扣减。
- 理论耗用 = POS 实销数量 × 已确认 BOM。
- 耗用差异 = 实际耗用 - 理论耗用，用于发现报损遗漏、多投料、盘点误差或丢失。
- 库存单位成本按多次入库移动加权平均，不用最后一次进货价覆盖历史成本。
- 商品理论毛利 = 销售收入 - 销量 × BOM 成本；店铺实际毛利需再用实盘耗用差异校准。

## 真实性边界

当前商品 BOM 尚缺预拌粉、酱料、木鱼花、海苔等单份克重；当每日使用记录不足时，补货预测必须返回“数据不足”。在 BOM、实销映射和连续实盘缺失时，不输出看似精确的单品毛利率、损耗率或断货日。

## 产物与审计

- 原始商品档案已复制到门店证据目录，原件未修改。
- 线下 Excel 含三类纸质流程：每日物料使用、阶段总库存盘点、进货台账；第四个工作表嵌入进货原始凭证索引。
- 每日纸质表为 A4 纵向单页，仓储品类不直接套用到员工表；另按营业取用路径分为“基础粉料 / 酱料 / 撒料 / 冷链配料 / 餐盒与袋装 / 出餐辅助耗材 / 标签与收银耗材”。全表只保留一次浅色列标题，固定 SKU、顺序、品名、规格和单位与线上录入页一致；只接受整数开封/领用次数，改错时覆盖原日记录而不重复扣库。
- 页面同时提供库存总览、使用、报损、阶段盘点、进货流水、生产批次、分析预警和表格下载。
- 审计场景已覆盖：首次基线、多次进货移动加权成本、订单去重、退款不入库、平替不重复建 SKU、使用与报损分离、门店→大冰箱→仓库自动扣减、改错失败回滚、账面不足时不产生负库存、盘点差异、无数据时不预测。
