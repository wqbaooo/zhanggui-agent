## 一、关键发现

### 1.1 财务危机（紧急）

内账核算调研测算出当前门店处于深度亏损状态：

```
月固定成本 = 房租 6500 + 人工 10500 + 水电 800 + 折旧 500 = 18300 元
月营收     ≈ 14000 元（日均约 467 元）
固定成本占比 = 131%（成本倒挂）

变动成本率 ≈ 44%（食材 30% + 包装 5% + 平台加权 8% + 税费 1%）
边际贡献率 = 56%
日保本营收 = 18300 ÷ 0.56 ÷ 30 ≈ 1089 元
当前营收仅达保本线 43%，月亏损约 7600-9000 元
```

> ⚠️ 需验证：月营收 1.4 万来自 `memory.json` 的 `daily_operations`/`monthly_revenue`，需确认是真实录入还是播种脚本模拟数据。但无论数据真伪，保本点分析功能必须建设。

### 1.2 行业基准对照

| 指标 | 行业基准 | 当前门店 | 状态 |
|---|---|---|---|
| 食材成本率 | 快餐 25-35% | 待核算（缺 BOM） | 未知 |
| 人工成本率 | 快餐 12-18% | 75% | 严重超标 |
| 房租占比 | ≤15%，商圈放宽 20% | 46% | 严重超标 |
| 食材损耗率 | 行业 8-15%，小店应 ≤5% | 无记录 | 未知 |
| 外卖综合费率 | 标注 6-8%，实际 20-26% | 未按实收核算 | 风险 |

### 1.3 现有功能缺口总览

| 模块 | 已实现 | 关键缺口 |
|---|---|---|
| 库存 | SKU + 进货 + 断货预测 | 无出库、无盘点、无效期、无损耗记录 |
| 账务 | 日利润 + 成本结构 + 周报框架 | 保本线未拆固定/变动、无 BOM 反算、无渠道利润对比 |
| 工资 | 四种计薪 + 月度汇总 + 摊销 | efficiency() bug、平均摊销失真、无排班、无节假日倍率 |
| 录入 | OCR 多策略 + 结构化草稿 + 证据链 | 无人工校正学习、无通用 CSV、无重复检测 |
| SOP | 文档库 + 版本管理 | 无执行层、无卫生检查表单、无训练关联，2 条 SOP 均为草稿 |

### P1 保本与亏损诊断（应对财务危机）

| # | 改进点 | 现状 | 方案 | 涉及文件 |
|---|---|---|---|---|
| 1.1 | 保本点仪表盘 | `calcBreakEvenDaily` 简化为日均总成本，未拆固定/变动 | 实现贡献毛益法：固定成本 ÷ 边际贡献率 = 保本营收 | `web/src/domain/calculations.ts`、`models/analytics.py` |

## 三、线下/电子台账结合方案

调研结论：个体工商户加盟小店应采用"纸质兜底合规 + 电子主线分析"双轨模式。

| 台账类型 | 纸质（线下） | 电子（线上） | 结合方式 |
|---|---|---|---|
| 采购台账 | 进货单据原件留存 | 拍照录入 → SKU 匹配 → 自动入库 | 纸质做凭证，电子做分析 |
| 销售台账 | 各平台结算单打印 | CSV 导入 / 截图识别 → 渠道拆分 | 纸质做对账，电子做趋势 |
| 库存台账 | 月末盘点表（手填） | 盘点录入 → 账实差异 → 自动报损 | 纸质做盘点，电子做核算 |
| 食安台账 | 晨检/消毒/留样表（商场要求） | 表单填写 → 拍照取证 → 到期提醒 | 纸质做合规，电子做预警 |
| 员工台账 | 考勤表/工资条签字 | 排班 → 考勤 → 工资核算 → 导出 | 纸质做留痕，电子做计算 |

核心原则：掌柜Agent 不替代纸质台账，而是优化"拍照/截图 → 识别 → 结构化归档 → 分析"链路，降低记账摩擦。

## 四、建议执行顺序

```
第 1 步：P0 紧急修复（1 天）
  → 修 efficiency bug + 标注 finance 废弃 + 验证周报

第 2 步：P1 保本与亏损诊断（3-5 天）
  → 保本仪表盘 + 亏损预警 + 渠道利润对比
  → 这是当前门店最迫切的需求

第 3 步：P2 库存深化 - 出库+盘点+效期（3-5 天）
  → 补全出入库闭环，让 current_stock 准确

第 4 步：P4 工资核算深化（3-5 天）
  → 修摊销 + 排班 + 节假日倍率（AGENTS.md 优先级 2）

第 5 步：P5 周报自动生成（2-3 天）
  → 验证 + 深化内容（AGENTS.md 优先级 3）

第 6 步：P3 内账核算 - BOM + 倒挤法（5-7 天）
  → BOM 是最大工程，但解决"手工录成本"根本问题

第 7 步：P6 运营管理深化（按需）
  → SOP 执行层 + 卫生检查 + 台账模板
```

总工期约 20-30 天，可根据实际情况调整。建议每步完成后验证再进入下一步。
