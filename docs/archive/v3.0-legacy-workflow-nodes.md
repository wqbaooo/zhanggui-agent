> **归档原因**：此方案已被 `graph/agent.py`（bind_tools + ToolNode 架构）取代。本文档记录设计思路、关键问题与经验教训，供后续类似项目参考。

> **状态**：已废弃，代码已归档
> **替代方案**：`graph/agent.py` + `graph/tools.py`

---

## 1. 背景

在将开店 Agent 从 V2 状态机迁移到 V3 LangGraph 架构时，最初的思路是：

- 用 **显式节点**（understand → plan → think → act → observe → reflect → decide → synthesize）构建 ReAct 循环
- 每个节点负责一个明确的推理步骤
- 通过条件边控制循环和 human-in-the-loop 中断

这个设计看起来清晰，但隐藏了一个根本性问题。

---

## 2. 核心设计

### 2.1 图结构

```
[START]
  ↓
[understand] — 理解用户输入，提取意图和画像
  ↓
[plan] — 生成/更新开店计划
  ↓
[think] — ReAct：分析当前状态，决定下一步行动
  ↓
[act] — 执行行动（调用工具或检索）
  ↓
[observe] — 整理工具返回结果
  ↓
[reflect] — 评估结果质量，识别风险
  ↓
[decide] — 决策：继续循环？中断？输出？
  ├─ 继续 → [think]
  ├─ 中断 → [interrupt] → END
  └─ 完成 → [synthesize] → END
```

### 2.2 状态定义

```python
class GraphState:
    user_input: str
    messages: List[BaseMessage]
    profile: Dict[str, Any]           # 画像（跨轮次累积）
    plan: Optional[Plan]              # 开店计划
    current_task: Optional[Task]
    completed_tasks: List[Task]
    pending_tasks: List[Task]
    thought: str                      # 当前思考
    action: str                       # 当前行动
    observation: str                  # 观察结果
    evidence: List[Evidence]          # 检索到的证据
    response: str                     # 给用户看的回复
    interrupt_reason: Optional[str]   # 中断原因
    options: List[str]                # 选项
    needs_human_input: bool           # 是否需要人工输入
```

### 2.3 节点职责

| 节点 | 职责 | 关键操作 |
|------|------|----------|
| `understand` | 意图分类 + 画像提取 | LLM 分析，失败时降级到关键词匹配 |
| `plan` | 生成/更新开店计划 | 调用 `generate_plan()`，创建 Phase/Task |
| `think` | ReAct：思考 | LLM 决定下一步行动 |
| `act` | 执行行动 | 根据 thought 调用工具（搜索/RAG/财务） |
| `observe` | 整理结果 | 格式化工具返回为 observation |
| `reflect` | 反思评估 | LLM 评估结果质量，识别风险 |
| `decide` | 决策 | 判断继续/中断/输出 |
| `synthesize` | 综合输出 | 生成最终回复 |

## 3. 关键问题诊断：关键词路由伪装成 LLM 推理

### 3.1 问题的本质

虽然每个节点都尝试调用 LLM 做推理，但代码中存在大量**降级逻辑**——当 LLM 调用失败、返回格式不对、或"为了保险"时，系统会退回到**硬编码的关键词匹配**。

### 3.2 典型症状

#### 症状 1：意图分类的关键词降级

```python
_FALLBACK_INTENT_KEYWORDS = {
    "选址诊断": ["选址", "商圈", "商铺", "位置", "地段", "客流", "动线", "铺位", "门面"],
    "选品决策": ["选品", "品类", "做什么", "项目", "什么品类"],
    "财务测算": ["成本", "利润", "租金", "回本", "投产", "流水", "盈亏", "预算", "多少钱"],
    "风险控制": ["风险", "避坑", "合同", "转让", "亏", "防骗", "加盟骗"],
    "营销运营": ["运营", "营销", "推广", "抖音", "团购", "开业活动", "引流", "美团"],
    "开店规划": ["规划", "方案", "计划", "怎么开", "准备开", "想开店", "能不能做", "可行性", "评估"],
}
```

> **问题**：用户输入"我想在万象城附近开个奶茶店，预算 30 万，帮我算一下回本周期"——这个词同时命中"选址诊断"（万象城）、"选品决策"（奶茶店）、"财务测算"（30 万、回本）。关键词路由无法处理这种**多意图交织**的真实场景，只能硬选一个或并列输出，失去了 LLM 的模糊推理能力。

#### 症状 2：画像提取的正则降级

```python
_FALLBACK_CITIES = ["北京", "上海", "广州", ...]  # 硬编码城市列表
_FALLBACK_CATEGORIES = {
    "早餐": ["早餐", "包子", "豆浆", ...],
    "粉面": ["面馆", "米粉", ...],
    ...
}
```

> **问题**：用户说"我在沙县想做点小生意"——沙县不在城市列表里；"我想做热干面"——热干面不在品类关键词里。正则降级只能处理**预先枚举的情况**，对新词、方言、模糊表达束手无策。

#### 症状 3：行动选择的条件判断

```python
def act_node(state):
    if "search" in state.action:
        return web_search(...)
    elif "rag" in state.action:
        return vector_search(...)
    elif "finance" in state.action:
        return calculate_finance(...)
```

> **问题**：LLM 的 `thought` 可能包含丰富的推理，但 `act` 节点用**字符串包含判断**来决定调用哪个工具。LLM 可能想"先查一下当地奶茶竞品密度，再算财务"，但字符串匹配只能执行单一工具，且对参数传递非常脆弱。

### 3.3 为什么这是"伪装"

| 表面 | 实际 |
|------|------|
| 每个节点都调用了 LLM | LLM 只做了"分类标签"或"文本生成" |
| 看起来有 ReAct 循环 | 真正的决策（调什么工具、传什么参数）被硬编码逻辑劫持 |
| 号称"LLM 优先，规则降级" | 生产环境中降级逻辑频繁触发，成为实际主路径 |
| 架构图很漂亮 | 运行时 LLM 的推理结果没有被真正执行 |

> **一句话总结**：LLM 被当成了"高级分类器"，而不是"推理引擎"。系统的真正决策权仍在关键词字典和 if-else 手里。

## 4. 经验教训

### 4.1 设计层面

1. **显式节点 vs 隐式推理**
   - 显式节点（understand/think/act/reflect）在纸面上很清晰
   - 但现实中，LLM 的推理是**连续的、模糊的、多跳的**
   - 强行把连续推理切成离散节点，会导致"推理断裂"——LLM 在 think 节点想好的方案，在 act 节点被关键词匹配扭曲

2. **降级逻辑是陷阱**
   - "LLM 优先，失败时降级到规则"听起来很安全
   - 实际上：
     - 开发时：降级逻辑容易被过度依赖（"反正有兜底"）
     - 生产时：LLM 偶发失败会静默降级，用户得到的是关键词匹配的劣质回复，却以为是 LLM 推理的结果
   - **建议**：要么全 LLM，要么全规则，不要混合。混合系统最难调试。

3. **工具调用必须让 LLM 直接参与**
   - 正确的模式：`bind_tools` + `ToolNode`，LLM 输出结构化工具调用（tool name + arguments）
   - 错误的模式：LLM 生成自由文本 → 正则/关键词提取工具名 → 硬编码映射到函数

### 4.2 工程层面

1. **状态管理过细**
   - `thought`, `action`, `observation` 分开存储，导致中间状态需要人工维护
   - 更好的方式：让 LLM 在消息历史中自然保留推理痕迹（Chain-of-Thought in messages）

2. **human-in-the-loop 与图的耦合**
   - 用条件边 `should_interrupt` 控制中断，导致中断逻辑散落在多个节点
   - 更好的方式：`interrupt()` 函数或 `ask_user` 工具，由 LLM 自己决定何时中断

3. **证据流与消息流分离**
   - `evidence` 列表和 `messages` 列表维护两套数据结构
   - 更好的方式：工具返回直接变成 `ToolMessage` 进入消息历史，LLM 自己从中提取证据

---

## 5. 替代方案：真正的 Agent 架构

当前已采用的新架构：

```
graph/agent.py   # bind_tools + ToolNode + ReAct 循环
graph/tools.py   # @tool 装饰器，5 个工具（搜索/RAG/财务/地图/追问）
graph/prompts.py # 苏格拉底辩证系统提示词
```

### 核心改进

| 维度 | 旧方案（本文档） | 新方案 |
|------|------------------|--------|
| **工具调用** | LLM 生成文本 → 关键词提取 → 硬编码映射 | `bind_tools`，LLM 直接输出 tool_calls（JSON） |
| **推理循环** | 固定节点序列（think→act→observe→reflect） | LLM 自主决定循环次数，ToolMessage 自动回流 |
| **中断机制** | 条件边 `should_interrupt` 硬编码判断 | `ask_user` 工具 + `interrupt()`，LLM 自己决定何时中断 |
| **意图理解** | LLM 分类 + 关键词降级 | LLM 从对话历史中自然理解，无显式分类节点 |
| **画像提取** | 正则匹配城市/品类/预算 | `update_profile` 工具，LLM 自主决定更新哪些字段 |
| **规划生成** | 独立 `plan` 节点生成 Plan 对象 | LLM 在推理过程中自主维护计划，无需显式数据结构 |

def understand_node(state: GraphState) -> Dict[str, Any]:
    """理解节点：通过LLM分析用户输入，提取意图和画像。LLM优先，规则降级。"""
    logger.info("[understand] 分析用户输入: %s", state.user_input[:50])

    llm = _get_llm()

    # ─── LLM意图分类 + 画像提取 ───
    intent = "通用咨询"
    extracted: Dict[str, Any] = {}
    intent_confidence = 0.0

    try:
        # 构建prompt：包含用户输入 + 历史画像
        prompt = UNDERSTAND_PROMPT.format(
            user_input=state.user_input,
            history_profile=json.dumps(state.profile, ensure_ascii=False, indent=2) if state.profile else "无",
        )

        response = llm.chat(prompt, temperature=0.2)
        content = response.get("content", "")

        # 尝试解析JSON
        try:
            result = json.loads(content)
            intent = result.get("intent", "通用咨询")
            extracted = result.get("extracted", {})
            intent_confidence = result.get("confidence", 0.8)
        except json.JSONDecodeError:
            # 尝试从文本中提取
            logger.warning("[understand] LLM返回非JSON，尝试正则提取: %s", content[:100])
            # 简单提取：找"意图"后面的词
            m = re.search(r'["\']?intent["\']?\s*[:=]\s*["\']?([^"\']+)', content)
            if m:
                intent = m.group(1).strip()
            # 找画像字段
            for field in ["city", "category", "budget", "experience", "business_mode"]:
                m = re.search(rf'["\']?{field}["\']?\s*[:=]\s*["\']?([^"\',}}\n]+)', content)
                if m:
                    extracted[field] = m.group(1).strip()
            intent_confidence = 0.5

    except Exception as exc:
        logger.error("[understand] LLM调用失败，降级到规则: %s", exc)
        intent = None  # 触发降级
        intent_confidence = 0.0

    # ─── 降级到关键词匹配（仅LLM失败时） ───
    if not intent or intent_confidence < 0.5:
        logger.info("[understand] 触发关键词降级")
        intent_scores = {}
        for intent_key, keywords in _FALLBACK_INTENT_KEYWORDS.items():
            score = sum(1 for kw in keywords if kw in state.user_input)
            if score > 0:
                intent_scores[intent_key] = score

        if intent_scores:
            intent = max(intent_scores, key=intent_scores.get)
        else:
            intent = "通用咨询"

        # 画像降级提取
        extracted = _fallback_extract_profile(state.user_input)
        intent_confidence = 0.3

    # 更新画像
    new_profile = dict(state.profile)
    for k, v in extracted.items():
        if v and str(v).strip():
            new_profile[k] = v
    new_profile["__intent__"] = intent
    new_profile["__intent_confidence__"] = intent_confidence

    return {
        "profile": new_profile,
        "messages": state.messages + [AIMessage(content=f"[理解] 意图: {intent}, 提取画像: {extracted}")],
    }


def _fallback_extract_profile(text: str) -> Dict[str, Any]:
    """降级画像提取：正则匹配。"""
    result: Dict[str, Any] = {}

    # 城市
    for city in _FALLBACK_CITIES:
        if city in text:
            result["city"] = city
            break

    # 品类
    for cat, keywords in _FALLBACK_CATEGORIES.items():
        if any(kw in text for kw in keywords):
            result["category"] = cat
            break

    # 预算（数字+万）
    m = re.search(r'(\d+)\s*万', text)
    if m:
        result["budget"] = int(m.group(1))

    # 经验
    if any(w in text for w in ["有经验", "做过", "干过", "开过"]):
        result["experience"] = "有经验"
    elif any(w in text for w in ["新手", "小白", "没经验", "第一次"]):
        result["experience"] = "新手"

    # 经营模式
    for mode, keywords in _FALLBACK_BUSINESS_MODES.items():
        if any(kw in text for kw in keywords):
            result["business_mode"] = mode
            break

    return result


def plan_node(state: GraphState) -> Dict[str, Any]:
    """规划节点：根据意图和画像生成/更新开店计划。"""
    logger.info("[plan] 生成计划，意图: %s", state.profile.get("__intent__"))

    intent = state.profile.get("__intent__", "通用咨询")

    # 根据意图决定是否需要生成计划
    if intent in ("开店规划", "选址诊断", "财务测算"):
        plan = generate_plan(state.profile)
        return {
            "plan": plan,
            "messages": state.messages + [AIMessage(content=f"[规划] 已生成开店计划: {plan.title if plan else '无'}")],
        }

    return {"messages": state.messages}


def think_node(state: GraphState) -> Dict[str, Any]:
    """思考节点：ReAct中的思考步骤。分析当前状态，决定下一步行动。LLM优先，规则降级。"""
    logger.info("[think] 思考节点")

    llm = _get_llm()

    # 构建思考上下文
    evidence_summary = "\n".join([f"- {e.type}: {e.content[:100]}" for e in state.evidence[-3:]]) if state.evidence else "无"
    plan_summary = str(state.plan) if state.plan else "无计划"

    try:
        prompt = THINK_PROMPT.format(
            user_input=state.user_input,
            profile=json.dumps(state.profile, ensure_ascii=False),
            plan=plan_summary,
            evidence=evidence_summary,
            history_thoughts=state.thought or "无",
        )

        response = llm.chat(prompt, temperature=0.3)
        content = response.get("content", "")

        # 尝试解析JSON
        try:
            result = json.loads(content)
            thought = result.get("thought", content)
            action = result.get("action", "respond")
        except json.JSONDecodeError:
            thought = content
            # 从文本中猜测行动
            action = _fallback_infer_action(content, state)

    except Exception as exc:
        logger.error("[think] LLM失败，降级: %s", exc)
        thought, action = _fallback_think(state)

    return {
        "thought": thought,
        "action": action,
        "messages": state.messages + [AIMessage(content=f"[思考] {thought[:200]}... → 行动: {action}")],
    }


def _fallback_infer_action(content: str, state: GraphState) -> str:
    """从思考文本中推断行动（降级）。"""
    content_lower = content.lower()
    if any(w in content_lower for w in ["搜索", "查", "找", "看看", "了解", "网上"]):
        return "search_web"
    elif any(w in content_lower for w in ["知识", "资料", "视频", "文档", "库"]):
        return "search_knowledge"
    elif any(w in content_lower for w in ["算", "计算", "财务", "成本", "利润", "租金"]):
        return "calculate_finance"
    elif any(w in content_lower for w in ["地图", "位置", "选址", "商圈", "高德"]):
        return "analyze_location"
    elif any(w in content_lower for w in ["问", "需要知道", "不清楚", "确认", "补充"]):
        return "ask_user"
    return "respond"


def _fallback_think(state: GraphState) -> tuple:
    """完全降级思考。"""
    intent = state.profile.get("__intent__", "通用咨询")
    if intent == "财务测算":
        return "需要进行财务测算", "calculate_finance"
    elif intent == "选址诊断":
        return "需要分析选址", "analyze_location"
    elif intent in ["选品决策", "开店规划"]:
        return "需要检索相关知识", "search_knowledge"
    elif should_search(state.user_input):
        return "需要联网搜索最新信息", "search_web"
    return "可以直接回复用户", "respond"


def act_node(state: GraphState) -> Dict[str, Any]:
    """行动节点：执行思考节点决定的行动。"""
    logger.info("[act] 执行行动: %s", state.action)

    action = state.action or "respond"
    result = ""

    try:
        if action == "search_web":
            from tools.web_search_tool import WebSearchTool
            tool = WebSearchTool()
            result = tool.search(state.user_input)
        elif action == "search_knowledge":
            from tools.vector_search_tool import VectorSearchTool
            tool = VectorSearchTool()
            result = tool.search(state.user_input, top_k=5)
        elif action == "calculate_finance":
            from tools.finance_tool import FinanceTool
            tool = FinanceTool()
            result = tool.calculate(state.profile)
        elif action == "analyze_location":
            from tools.map_tool import MapTool
            tool = MapTool()
            city = state.profile.get("city", "")
            result = tool.analyze(city)
        elif action == "ask_user":
            # 中断，需要用户输入
            return {
                "needs_human_input": True,
                "interrupt_reason": "需要补充信息",
                "options": _generate_fallback_options(state),
            }
        else:
            result = "直接回复用户，无需调用工具。"
    except Exception as exc:
        logger.error("[act] 工具执行失败: %s", exc)
        result = f"工具执行失败: {exc}"

    return {
        "observation": result,
        "messages": state.messages + [AIMessage(content=f"[行动] {action} → {result[:200]}")],
    }


def _generate_fallback_options(state: GraphState) -> List[str]:
    """生成追问选项（降级）。"""
    missing = []
    if not state.profile.get("city"):
        missing.append("请问您在哪个城市开店？")
    if not state.profile.get("category"):
        missing.append("请问您想做什么品类？")
    if not state.profile.get("budget"):
        missing.append("请问您的预算大概是多少？")
    if not missing:
        missing.append("请问还有其他需要补充的信息吗？")
    return missing[:3]


def observe_node(state: GraphState) -> Dict[str, Any]:
    """观察节点：整理行动结果。"""
    observation = state.observation or ""

    # 创建证据
    new_evidence = Evidence(
        type="observation",
        content=observation[:500],
        source="tool_execution",
    )

    return {
        "evidence": state.evidence + [new_evidence],
        "messages": state.messages + [AIMessage(content=f"[观察] {observation[:200]}")],
    }


def reflect_node(state: GraphState) -> Dict[str, Any]:
    """反思节点：评估结果质量，识别风险。LLM优先，规则降级。"""
    logger.info("[reflect] 反思节点")

    llm = _get_llm()

    try:
        evidence_summary = "\n".join([f"- {e.type}: {e.content[:100]}" for e in state.evidence[-3:]]) if state.evidence else "无"

        prompt = REFLECT_PROMPT.format(
            user_input=state.user_input,
            thought=state.thought or "无",
            observation=state.observation or "无",
            evidence=evidence_summary,
            profile=json.dumps(state.profile, ensure_ascii=False),
        )

        response = llm.chat(prompt, temperature=0.3)
        content = response.get("content", "")

        try:
            result = json.loads(content)
            reflection = result.get("reflection", content)
            has_risk = result.get("has_risk", False)
            risk_level = result.get("risk_level", "low")
            next_step = result.get("next_step", "respond")
        except json.JSONDecodeError:
            reflection = content
            has_risk = any(w in content for w in ["风险", "坑", "注意", "警惕", "问题"])
            risk_level = "medium" if has_risk else "low"
            next_step = "respond"

    except Exception as exc:
        logger.error("[reflect] LLM失败，降级: %s", exc)
        reflection, has_risk, risk_level, next_step = _fallback_reflect(state)

    # 如果有风险，添加风险证据
    new_evidence = list(state.evidence)
    if has_risk:
        new_evidence.append(Evidence(
            type="risk",
            content=reflection[:300],
            source="reflection",
            metadata={"level": risk_level},
        ))

    return {
        "evidence": new_evidence,
        "messages": state.messages + [AIMessage(content=f"[反思] {reflection[:200]}... 风险: {has_risk}")],
    }


def _fallback_reflect(state: GraphState) -> tuple:
    """降级反思。"""
    intent = state.profile.get("__intent__", "")
    risk_checks = {
        "加盟": ["加盟费", "保证金", "品牌", "合同"],
        "选址": ["转让费", "房东", "合同", "拆迁"],
        "财务": ["亏损", "现金流", "负债"],
    }

    for key, keywords in risk_checks.items():
        if key in intent:
            for kw in keywords:
                if kw in state.user_input:
                    return f"发现潜在风险关键词: {kw}", True, "medium", "respond"

    return "未发现明显风险", False, "low", "respond"


def decide_node(state: GraphState) -> Dict[str, Any]:
    """决策节点：决定下一步。继续循环？中断？输出？LLM优先，规则降级。"""
    logger.info("[decide] 决策节点")

    llm = _get_llm()

    try:
        evidence_summary = "\n".join([f"- {e.type}: {e.content[:80]}" for e in state.evidence[-3:]]) if state.evidence else "无"

        prompt = DECIDE_PROMPT.format(
            user_input=state.user_input,
            profile=json.dumps(state.profile, ensure_ascii=False),
            thought=state.thought or "无",
            observation=state.observation or "无",
            evidence=evidence_summary,
            loop_count=len(state.evidence),
        )

        response = llm.chat(prompt, temperature=0.2)
        content = response.get("content", "")

        try:
            result = json.loads(content)
            decision = result.get("decision", "respond")
            reason = result.get("reason", "")
            needs_human = result.get("needs_human_input", False)
            options = result.get("options", [])
        except json.JSONDecodeError:
            decision = _fallback_decide(state, content)
            reason = content[:100]
            needs_human = "问" in content or "确认" in content
            options = []

    except Exception as exc:
        logger.error("[decide] LLM失败，降级: %s", exc)
        decision, reason, needs_human, options = _fallback_decide(state, ""), "降级决策", False, []

    return {
        "needs_human_input": needs_human,
        "interrupt_reason": reason if needs_human else None,
        "options": options if needs_human else [],
        "messages": state.messages + [AIMessage(content=f"[决策] {decision} - {reason[:100]}")],
    }


def _fallback_decide(state: GraphState, content: str) -> str:
    """降级决策。"""
    if state.needs_human_input:
        return "interrupt"
    if len(state.evidence) >= 5:
        return "respond"
    if any(w in content for w in ["继续", "再查", "还需要"]):
        return "continue"
    return "respond"


def synthesize_node(state: GraphState) -> Dict[str, Any]:
    """综合节点：生成最终回复。LLM优先，规则降级。"""
    logger.info("[synthesize] 综合输出")

    llm = _get_llm()

    try:
        evidence_text = "\n".join([f"[{e.type}] {e.content[:150]}" for e in state.evidence]) if state.evidence else "无证据"

        prompt = SYNTHESIZE_PROMPT.format(
            user_input=state.user_input,
            profile=json.dumps(state.profile, ensure_ascii=False),
            thought=state.thought or "无",
            evidence=evidence_text,
            plan=str(state.plan) if state.plan else "无",
        )

        response = llm.chat(prompt, temperature=0.5)
        content = response.get("content", "")

    except Exception as exc:
        logger.error("[synthesize] LLM失败，降级: %s", exc)
        content = _fallback_synthesize(state)

    return {
        "response": content,
        "messages": state.messages + [AIMessage(content=f"[回复] {content[:200]}")],
    }


def _fallback_synthesize(state: GraphState) -> str:
    """降级综合回复。"""
    intent = state.profile.get("__intent__", "通用咨询")
    evidence_summary = "\n".join([e.content[:100] for e in state.evidence[-2:]]) if state.evidence else ""

    templates = {
        "选址诊断": f"根据您的描述，选址分析如下：\n{evidence_summary}\n\n建议实地考察后再做决定。",
        "财务测算": f"财务测算结果：\n{evidence_summary}\n\n以上数据仅供参考，实际经营可能有所不同。",
        "选品决策": f"关于品类选择：\n{evidence_summary}\n\n建议结合当地消费习惯综合考虑。",
        "风险控制": f"风险提示：\n{evidence_summary}\n\n建议在签约前咨询专业人士。",
    }

    return templates.get(intent, f"感谢您的咨询。\n\n{evidence_summary}\n\n如有其他问题欢迎继续提问。")


def _interrupt_node(state: GraphState) -> Dict[str, Any]:
    """中断节点：处理人机交互。"""
    logger.info("[interrupt] 中断，原因: %s", state.interrupt_reason)

    # 构建中断消息
    interrupt_msg = state.interrupt_reason or "需要您的确认"
    options = state.options or []

    response = f"{interrupt_msg}\n"
    if options:
        response += "\n".join([f"{i+1}. {opt}" for i, opt in enumerate(options)])

    return {
        "response": response,
        "needs_human_input": True,
    }

### 6.2 graph/graph.py

```python
#!/usr/bin/env python3
# -*- coding: utf-8 -*-
"""LangGraph构建器：创建ReAct + Planning + Human-in-the-loop工作流。"""

from __future__ import annotations

import logging
from typing import Any, Dict, Literal

from langgraph.graph import StateGraph, END
from langgraph.checkpoint.memory import MemorySaver

from graph.nodes import (
    understand_node, plan_node, think_node, act_node,
    observe_node, reflect_node, decide_node, synthesize_node
)
from graph.state import GraphState

logger = logging.getLogger(__name__)


def should_interrupt(state: GraphState) -> Literal["interrupt", "continue"]:
    """判断是否需要中断（人机交互）。"""
    if state.needs_human_input:
        return "interrupt"
    return "continue"


def should_continue_react(state: GraphState) -> Literal["think", "synthesize"]:
    """判断ReAct循环是否继续。"""
    # 如果已经达到目标或需要人机交互，停止循环
    if state.needs_human_input:
        return "synthesize"
    
    # 如果已经执行了足够多的行动（防止无限循环）
    if len(state.evidence) >= 10:
        return "synthesize"
    
    # 如果当前行动已经获取了足够信息
    if state.observation and len(state.observation) > 100:
        return "synthesize"
    
    # 否则继续思考→行动循环
    return "think"


def build_graph() -> StateGraph:
    """构建LangGraph工作流。"""
    
    # 创建工作流
    workflow = StateGraph(GraphState)
    
    # 添加节点
    workflow.add_node("understand", understand_node)
    workflow.add_node("plan", plan_node)
    workflow.add_node("think", think_node)
    workflow.add_node("act", act_node)
    workflow.add_node("observe", observe_node)
    workflow.add_node("reflect", reflect_node)
    workflow.add_node("decide", decide_node)
    workflow.add_node("synthesize", synthesize_node)
    workflow.add_node("interrupt", _interrupt_node)
    
    # 定义边
    workflow.set_entry_point("understand")
    workflow.add_conditional_edges(
        "understand", should_interrupt,
        {"interrupt": "interrupt", "continue": "plan"}
    )
    workflow.add_conditional_edges(
        "plan", should_interrupt,
        {"interrupt": "interrupt", "continue": "think"}
    )
    workflow.add_edge("think", "act")
    workflow.add_edge("act", "observe")
    workflow.add_edge("observe", "reflect")
    workflow.add_conditional_edges(
        "reflect", should_interrupt,
        {"interrupt": "interrupt", "continue": "decide"}
    )
    workflow.add_conditional_edges(
        "decide", should_continue_react,
        {"think": "think", "synthesize": "synthesize"}
    )
    workflow.add_edge("synthesize", END)
    workflow.add_edge("interrupt", END)
    
    memory = MemorySaver()
    graph = workflow.compile(checkpointer=memory)
    
    return graph
```

## 7. 总结

这个旧方案的核心教训是：**不要给 LLM 戴枷锁**。当我们把 LLM 的输出强行塞进预定义的节点和降级规则时，LLM 的推理能力就被架空了。真正的 Agent 应该让 LLM 直接决定调用什么工具、传什么参数、何时中断、何时输出——而 `bind_tools` 正是为此设计的。

> "LLM 不是分类器，它是推理引擎。"
