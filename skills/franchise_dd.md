# 加盟尽调
## trigger
加盟、品牌、连锁、代理、快招、招商、特许经营、品牌方、总部

## methodology
### 7步尽职调查
| 步 | 检查项 | 通过标准 |
|----|--------|---------|
| 1-合规 | 商务部备案 + 品牌成立>2年 + 直营店≥2家经营>1年 | 三项全满足 |
| 2-门店 | 不通过品牌方，自行走访3家以上加盟店 | 至少2家经营良好 |
| 3-访谈 | 和3位加盟商单独沟通(不在品牌方在场时) | 真实信息 |
| 4-全成本 | 加盟费+保证金+设备(含溢价)+装修(含溢价)+首批物料+培训+开业+3月运营金 | 在预算内 |
| 5-合同 | 律师审查 | 无重大不公平 |
| 6-闭店率 | 搜索'[品牌]加盟倒闭/亏' | 闭店率<30% |
| 7-匹配 | 资金/时间/管理能力 vs 品牌要求 | ≥60% |

### 判断矩阵
- 7步全通过 → Go
- 5-6步通过 → Conditional Go
- 3-4步通过 → Needs More Data
- ≤2步通过 → No-Go

## domain_knowledge
### 法律红线
《商业特许经营管理条例》(2007):
- 特许人必须拥有至少 2 个直营店，经营超过 1 年（"两店一年"）
- 必须向商务部备案，未备案的加盟行为违规
- 签订合同前至少 30 日书面披露信息
- 被特许人享有冷静期内的反悔权

### 快招公司5秒识别
以下模式出现任意2条 → 高度疑似快招：
- 品牌成立不到2年（违反"两店一年"）
- 承诺"3-4个月回本""月入3-5万"（正常回本8-18月）
- 催促签约"名额有限""本周优惠截止"
- 不让联系其他加盟商、"商业机密"为由拒绝
- 签约地在写字楼而非门店
- 抖音/小红书大量投流招商内容

### 品类成本差异
**茶饮**：加盟费5-15万，总投资30-80万。设备溢价40%是常态。闭店率：一线30-40%，三四线50-70%。品牌生命周期2-3年。
**快餐小吃**：加盟费3-8万，总投资15-40万。核心利润在供应链（强制采购酱料/原料）。加盟商真实利润率<10%。
**火锅**：加盟费10-30万，总投资80-200万。回本18-24月。人工成本高，选址要求严格。

### 加盟 vs 自营
什么时候加盟：
- 没餐饮经验，品类有品牌认知度门槛（如茶饮）
- 品牌供应链有不可替代优势
- 品牌运营支持体系经过验证

什么时候自营：
- 有经验或品类门槛低（小吃、早餐）
- 预算有限，加盟溢价占比过高
- 三四线城市，品牌影响力有限

## output_guidance
- **合规检查永远排第一**：先判断品牌有没有加盟资格（两店一年+商务部备案），不合规直接No-Go，不需要继续分析
- 如果合规通过，再进入7步尽调
- 快招识别贯穿全程：成立时间/回本承诺/催签行为中任意2条 → 高度疑似
- 最后才做财务测算（因为数据依赖前几步的验证）
- 验证网址：商务部 txjy.syggs.mofcom.gov.cn
