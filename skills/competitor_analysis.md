# 竞品分析
## trigger
竞品、竞争、同行、对手、市场、差异化、对比、选品、品类选择

## methodology
### SWOT-TOWS 策略矩阵
从SWOT分析推导可执行策略：
- SO策略（优势×机会）：用自身优势抓住市场机会
- WO策略（劣势×机会）：补短板以抓住机会
- ST策略（优势×威胁）：用优势防御外部威胁
- WT策略（劣势×威胁）：防御性策略，避免最坏情况

### 蓝海战略
寻找差异化空间。四步：
1. 列出行业公认的竞争要素
2. 哪些可以剔除？（顾客不需要的）
3. 哪些可以降到行业标准以下？
4. 哪些需要提升到行业标准以上？
5. 哪些是行业从未提供的？（这是蓝海）

餐饮业真正的蓝海极少，多数是微创新。不要为了差异化而差异化。

### 品类生命周期
- 导入期：市场教育成本高，但先发优势明显
- 成长期：快速扩张窗口，竞争加剧但市场在扩大
- 成熟期：品牌化竞争，利润空间缩小
- 衰退期：替代品类出现，考虑转型

判断标准：该品类在目标城市是"新概念"还是"老品类"？如果是新概念——导入期，需要教育市场。如果是老品类——成熟期，需要差异化。

## domain_knowledge
### 下沉市场竞品特征
- 线上数据覆盖率低（美团收录不全、高德POI滞后）
- 口碑传播比线上评价更有影响力
- 价格敏感度更高（客单价天花板明显）
- 品牌忠诚度高于一二线（一旦建立信任，复购率更高）

### 竞品分析数据维度
- 同品类数量（500m内）
- 价格带分布（最低/最高/集中区间）
- 评分分布（美团/大众点评）
- 月销量估算（外卖平台数据）
- 评价关键词（好评高频词 vs 差评高频词）
- 营业时间覆盖

## output_guidance
- 先查再分析：用 analyze_location / analyze_competition 工具
- 用对比表呈现，不做散文
- 识别差异化机会：竞品做得不好的、竞品没做的
- 判断竞争强度：蓝海（<3家）→ 竞争区（4-6家）→ 红海（≥7家）
- 标注数据来源和置信度
