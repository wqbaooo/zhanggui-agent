# 运营管理
## trigger
运营、管理、出品、库存、排班、效率、服务员、员工、翻台、SOP、日常

## methodology
### 精益创业 MVP
1. Build：最小可行产品（先摆摊/快闪测试）
2. Measure：收集数据（日单量、客单价、复购率、顾客反馈）
3. Learn：调整或坚持
餐饮MVP周期比软件长（不是3天，是3-4周），不要追求"完美产品再开业"。

### 约束理论 TOC
1. 找到系统瓶颈（出餐速度？备料？服务？翻台？）
2. 最大化瓶颈的利用率
3. 让其他环节服从瓶颈的节奏
4. 提升瓶颈能力
5. 瓶颈转移后重复步骤1

餐饮最常见的瓶颈：饭点出餐速度。表现：顾客等太久 → 差评 → 复购崩塌。解决：提前备料、优化动线、简化菜单。

### 排队论
- M/M/1 模型：平均等待时间 = 服务时间/(1-利用率)
- 利用率 > 80% → 等待时间指数增长
- 关键：高峰期不要追求 100% 利用率，保持 70-80% 缓冲

## domain_knowledge
### 出品 SOP 标准化
新员工 1 天上手的标准：
- 配方卡：克重/时间/步骤/图片
- 动线设计：拿料→制作→出餐 3 步内完成
- 高峰期预制：可以提前准备的（酱料、配菜）在高峰前备好

### 日运营节奏（小吃店参考）
| 时间 | 任务 |
|------|------|
| 8:00-9:00 | 备料、设备检查、清洁 |
| 9:00-11:00 | 备餐高峰用物料 |
| 11:00-14:00 | 午高峰（全员） |
| 14:00-16:00 | 补料、午休（轮班） |
| 16:00-20:00 | 晚高峰（全员） |
| 20:00-21:00 | 收档、清洁、盘点、报货 |

### 库存管理
- 安全库存 = 日均用量 × 采购周期 × 1.5
- FIFO 先进先出
- 每周盘点 1 次（食材）+ 每月盘点 1 次（物料）
- 食材损耗率目标 ≤ 3%

### 人力配置
- 小吃店最低配置：1 人（老板自己做 + 备餐 + 收银 + 清洁）
- 标准配置：2 人（1 制作 + 1 服务/收银）
- 人力成本目标：≤ 20-25% 营收
- 绩效设计：底薪 + 营业额提成（激励出品速度和服务质量）

## output_guidance
- 针对用户的具体品类和规模给建议
- 区分开业阶段 vs 稳定运营阶段
- 用具体人数和数字，不说"适当增加人手"
- 引用行业基准值作为对比参考
