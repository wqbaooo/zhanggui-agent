# 开店做生意Agent知识库

## 1. 勇哥说餐饮核心理论

### 1.1 360度看商圈方法
- **有效客流**：有效客流 = 目标客群 × 停留意愿 × 消费能力
- **客群画像**：通过观察路人年龄、穿着、状态判断客群类型
- **竞争生态**：分析周边竞争，寻找生态位，避免同质化
- **场景与时间**：分析不同时段的客流情况，匹配经营时间

### 1.2 四步分析逻辑
- **第一步**：经营状况梳理定底线（日营业额/毛利/房租/人工/水电杂费）
- **第二步**：投资与背景调查定抗风险能力（总投资与分布/负债/加盟&自营模式/餐饮经验）
- **第三步**：商圈与环境评估定客流上限（客流质量/周边业态/竞争环境/周边数据）
- **第四步**：三维交叉验证结论判断（能不能活/盈利潜力/风险等级）

### 1.3 避坑铁律
- **资金铁律**：只用闲钱，不动养老、教育、抚恤金；不网贷、不抵押、不借高息；总投入≤存款30%，预留6个月备用金
- **加盟防骗铁律**：没在商务部特许经营备案=一律不碰；只看真实在营店，不看样板间；不被"限时优惠、只剩最后一席"逼单
- **选址铁律**：蹲点早中晚+周末数人流，看真实客流；避开施工、拆迁、冷门楼层、偏远位置；同类店密集区慎入
- **品类选择铁律**：新手避开：咖啡、奶茶、汉堡、烘焙、网红轻餐饮；优先：社区刚需、低装修、低人工、复购高的小生意
- **止损铁律**：连续3个月不盈利，直接关店，不硬扛；不追加投资"救店"，越救亏越多

### 1.4 经典案例
- **早餐哥**：卖包子因早上起不来而倒闭，后开麻辣火锅店负债55万，最终在勇哥建议下开社区面馆
- **脸盆姐**：在蜜雪冰城旁边开鲜榨果汁店，设备只有脸盆，日营业额60元
- **两江总督**：拿60万投奶茶品牌代理，结果亏损严重
- **七层奶茶大厦**：成本核算（日支高）+ 投资背景（抵押房产高负债）+ 商圈环境（郊区客流少 / 竞品 3 家）→ 必倒闭

## 2. 开店选址理论

### 2.1 选址核心模型
- **人-流-场模型**：人（目标客群）、流（有效流量）、场（消费场景）
- **租金营收比**：月营业额至少达到月租金的5倍，才能触及盈利门槛
- **金角银边草肚皮法则**：街角铺位（金角）展示面强、客流集中；街道两端（银边）次之；中间区域（草肚皮）慎选

### 2.2 不同场景选址策略
- **写字楼密集区**：适合"一人食简餐、快餐"，客群是上班族（午高峰集中，客单价25-35元）
- **社区周边**：适合"家庭聚餐、日常便餐"，客群是居民（晚高峰+周末为主，客单价30-50元）
- **商圈/学校附近**：适合"高性价比小吃、网红餐饮"，客群是年轻人（追求新鲜，复购靠"打卡"）
- **地铁口**：客流如织但90%是赶路的，只路过不消费，叫"无效客流"

### 2.3 选址评估方法
- **实地蹲点**：分时段（早、中、晚、工作日、周末）蹲点，观察门前经过的人是否可能进店消费
- **竞争分析**：避免"扎堆"——如果500米内有3家同品类店，除非有"绝对优势"，否则慎选
- **政策风险**：确认商铺是否"可明火"（餐饮需消防验收）、是否"允许外摆"（影响堂食+外卖）、是否有"拆迁计划"

## 3. 选品策略

### 3.1 选品核心原则
- **市场需求导向**：不是"我喜欢"，而是"市场需要"
- **受众广度**：选择覆盖全年龄段、无明显淡旺季的品类
- **供应链成熟度**：选择供应链稳定、标准化程度高的品类
- **差异化**：避免选"烂大街"的品类，除非有"独家秘方"

### 3.2 2026年推荐品类
- **社区便民快餐**：依托"一刻钟便民生活圈"政策，租金比商圈低40%-60%，20-80平小店就能干，启动资金10-20万
- **地方特色单品小吃**：选非遗/地域特色小吃，口味独特、记忆点强，避开同质化红海
- **健康养生功能餐**：低脂低糖、营养透明的餐饮增速20%+，适合老人小孩
- **AI赋能迷你外卖档口**：10-20平档口起步，主打1-2款爆款，配自助点餐机、智能取餐柜，1个人就能看店

### 3.3 选品调研方法
- **客群画像**：用百度指数、美团"商圈热力图"分析周边人群
- **消费能力**：观察周边商铺定价，客单价应匹配客群消费力
- **需求缺口**：用"大众点评+美团"搜索周边3公里内的餐饮类型，寻找缺口
- **毛利率计算**：食材成本占比建议控制在30%-40%

## 4. 成本核算和财务管理

### 4.1 成本结构
- **健康的单店成本结构**：
  - 食材成本：35%-40%
  - 人力成本：20%-25%
  - 租金成本：15%-20%（不宜突破红线）
  - 水电杂费等：约10%
  - 净利润率：10%-15%

### 4.2 核心计算公式
- **毛利润** = 营业收入 - 营业成本
- **净利润** = 毛利润 - 各项费用
- **毛利率** = (毛利润 / 营业收入) × 100%
- **净利率** = (净利润 / 营业收入) × 100%
- **人效** = 月营业额 / 员工数（月人均营业额低于2万元是危险信号）

### 4.3 成本控制方法
- **固定成本**：摊薄刚性支出（房租、基本工资、税费、水电、分摊费用等）
- **可变成本**：弹性优化（原材料、营销费用、临时工资等）
- **预警机制**：
  - 人效预警：月人均营业额低于2万元是危险信号
  - 现金流预警：务必预留覆盖3-6个月固定成本的备用金
  - 损耗预警：食材报废率＞5%时触发调整
  - 能耗预警：水电费超预算10%启动节能方案

## 5. 运营管理技巧

### 5.1 产品管理
- **标准化**：用中央厨房或半成品降低对厨师的依赖，确保"每份菜味道一致"
- **迭代更新**：每月推出1-2道"季节限定菜"，保持顾客新鲜感
- **包装升级**：外卖用"防洒餐盒+保温袋"，堂食用"分餐制小碟"提升仪式感

### 5.2 服务管理
- **细节服务**：顾客带娃送儿童椅，老人就餐主动调小火候，外卖附"加热小贴士"
- **会员体系**：消费满100元送"5元无门槛券"（下次使用），生日送"免费菜品"，提升复购
- **用户反馈**：桌上放"好评返现卡"（返5元红包），收集差评及时改进

### 5.3 营销推广
- **地推+团购组合拳**：开业3天发放免费试吃券，搭配美团套餐
- **社交平台内容引爆**：发布"开业送啤酒"抖音视频，小红书发布"菜品出锅"图文笔记
- **跨界联合营销**：与健身房推出"健身餐套餐"，与快递点合作"午餐代收服务"
- **私域流量**：通过500人微信群实现月均复购4.2次，客单价提升28%

## 6. 风险控制和避坑指南

### 6.1 常见失败原因
- **懒于调研**：信加盟躺赚
- **无视市场**：情怀大于生意
- **乱投钱**：无现金流底线
- **选址瞎选**：不懂人流与竞争
- **被快招套路**：合同全是坑

### 6.2 加盟防骗指南
- **查品牌备案**：没在商务部特许经营备案=一律不碰
- **看真实店铺**：只看真实在营店，不看样板间
- **防逼单**：不被"限时优惠、只剩最后一席"逼单
- **合同审查**：合同必须写：退出机制、物料价格、商圈保护、违约责任
- **识别骗局**：承诺稳赚、保本、快速回本=100%骗局

### 6.3 止损策略
- **连续3个月不盈利**：直接关店，不硬扛
- **不追加投资"救店"**：越救亏越多
- **设定止损线**：到点就停，不要抱有侥幸心理

## 7. 单店盈利模型

### 7.1 核心公式
- **净利润** = 交易客数量 × 平均客单价 × 综合毛利率 – 成本费用
- **交易客数量** = 入店人数 × 成交率
- **客单价** = 消费单价 × 购买数量

### 7.2 流量优化
- **扩大入店人数**：店址与客流匹配、品牌与形象赋能、全渠道营销引流、老客留存稳流
- **提升成交率**：商品与需求精准匹配、服务与专业双重加持、异议处理与体验升级、漏斗分析定位问题

### 7.3 客单价提升
- **优化消费单价**：精准定价匹配客群、合理搭配价位线、引导价格升级
- **增加购买数量**：丰富品类满足多元需求、关联推荐激发潜在消费、场景化陈列引导搭配、促销活动刺激多买

### 7.4 毛利优化
- **定价策略**：根据成本结构和竞争环境制定合理价格
- **品类结构**：优化高毛利品类占比
- **成本控制**：优化采购渠道、减少浪费、提高库存管理效率
